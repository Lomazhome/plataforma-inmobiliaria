Metrocuadrado
Portal #1 de Colombia - El Tiempo / Portafolio
Sin configurar
Credenciales de acceso
Como obtener tu API Key:
1. Ingresa a metrocuadrado.com con tu cuenta de inmobiliaria
2. Ve a Mi Cuenta > Configuracion > Integraciones > API
3. Genera una nueva API Key y copia el valor
4. Pega la key aqui y guarda. La integracion se activara automaticamente.

Nota: Metrocuadrado requiere cuenta de inmobiliaria verificada (plan de pago). Ver planes →
🏡
Finca Raiz
Portal inmobiliario especializado de Colombia
Sin configurar
Credenciales API
Como obtener tu API Key de Finca Raiz:
1. Registrate como integrador en fincaraiz.com.co
2. Solicita tu API Key al equipo de Finca Raiz (proceso de verificacion de inmobiliaria).
3. Finca Raiz te entregara un API Key y un Client ID (formato UUID).
4. Pega el API Key arriba y el Client ID abajo, luego haz clic en "Guardar".
5. Al publicar desde LoMaz Home, el inmueble se enviara a Finca Raiz en estado Pendiente.
6. Activa los inmuebles desde tu panel en Finca Raiz o via el endpoint /listing/status.

Nota: Requiere cuenta de inmobiliaria verificada y plan activo en Finca Raiz. Ver doc API

Proppit (x6 portales)
Publica simultaneamente en Metrocuadrado, Finca Raiz, Properati, Lamudi, Vivendo y mas
Sin configurar
Token de integracion Proppit
🌟 Con un solo token publicas en 6 portales:
Metrocuadrado, Finca Raiz, Properati, Lamudi, Vivendo, Icasas

Como obtenerlo:
1. Crea cuenta en proppit.com como inmobiliaria
2. Ve a Configuracion > Integraciones > API Token
3. Genera y copia tu token de acceso
4. Pega aqui - todas tus propiedades se distribuiran automaticamente.

Facebook Marketplace
Publicacion via Graph API - requiere pagina de Facebook
Sin configurar
Credenciales Graph API
Requisitos Facebook Marketplace API:
1. Debes tener una Pagina de Facebook verificada como negocio
2. Solicita acceso a la API de Marketplace en: developers.facebook.com
3. Crea una app, obtiene permisos pages_manage_posts y catalog_management
4. Genera un Page Access Token de larga duracion (60 dias)

Importante: Meta (Facebook) requiere aprobacion de la app para publicar en Marketplace de forma automatica. El proceso puede tomar 2-4 semanas.
📷
Instagram
Publicacion automatica via Instagram Graph API
Sin configurar
Credenciales Instagram Graph API
Requisitos Instagram Graph API:
1. Cuenta de Instagram debe ser Business o Creator
2. Vincula la cuenta de Instagram a tu Pagina de Facebook
3. En developers.facebook.com crea app con permiso instagram_content_publish
4. Genera un token de larga duracion (60 dias renovable)

Funcionamiento: Al publicar una propiedad, se crea automaticamente un post con la primera imagen y caption optimizado con hashtags.

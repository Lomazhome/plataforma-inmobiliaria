🔑 Client ID de Google:¿Cómo obtenerlo?
Pasos (una sola vez):
1. Entra a console.cloud.google.com y crea un proyecto.
2. En "APIs y servicios" → habilita Google Calendar API.
3. En "Credenciales" → Crear credenciales → ID de cliente de OAuth → tipo Aplicacion web.
4. En "Origenes autorizados de JavaScript" agrega: https://www.lomazhome.com
5. Copia el Client ID (termina en .apps.googleusercontent.com) y pegalo arriba.
